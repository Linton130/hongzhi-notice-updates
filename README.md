# 红字通知单工具 · 更新发布库

本仓库**只存放安装包与发布说明**，源码在私有仓库，不对外公开。

## 下载安装

请在 Releases 中下载最新的 `RedNoticeTool_Setup_v<版本>.exe` 安装包，双击安装即可（按用户安装，无需管理员权限）。

## 软件内更新

软件启动时会自动检查本仓库的最新 Release：

- 有新版本 → 托盘气泡提示 → 点气泡打开「软件更新」窗 → 点「立即更新」自动下载安装并重启；
- 也可在托盘右键「检查更新」，或「后台管理 → 系统设置 → 立即检查更新」；
- 升级只替换程序文件，`data`（账号/配置/历史）、`输出结果`、`归档` 全部保留。

## 说明

- 安装包资产名固定为 `RedNoticeTool_Setup_v<版本>.exe`，Tag 为 `v<版本>`（与软件版本号一致）。
- 本仓库不含任何业务数据、账号或配置。
